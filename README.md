# Naked Vision TV

A Next.js web application for Naked Vision TV.

## Getting Started

### Development

```bash
yarn install
yarn dev
```

The application will be available at `http://localhost:5000`.

### Building

```bash
yarn build
yarn start
```

### Testing

This project uses Jest and React Testing Library for testing.

```bash
# Run all tests
yarn test

# Run tests in watch mode
yarn test:watch
```

## Project Structure

- `pages/` - Next.js pages
- `components/` - React components
- `__tests__/` - Test files
- `public/` - Static assets

## Technologies

- Next.js 9.1.3
- React 16.12.0
- Jest 27
- React Testing Library 12
